# Felicity Pharma

A static editorial website with a procedural React Three Fiber DNA sculpture.

## Design references

- https://omanta.com/
- https://seniora.framer.website/
- https://www.paratushealth.com/
- https://www.kaigohealth.ai/
- https://www.reactbits.dev/
- https://recent.design/i/atj1h6z-superpower

The design uses these references for a polished, dimensional visual direction. The footer includes social media links.

## Development

Install Node.js and npm, then run:

```sh
npm install
npm run dev
```
